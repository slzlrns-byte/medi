# 결정 로그

설계 초안 v0.6 기준. 출처는 [`design-map.html`](design-map.html)의 각 절이며, 아래 날짜는 모두 결정이 문서에 반영된 날짜입니다.

---

- **2026-08-17 · 앱 이름 = 더잔잔 / The Janjan** (확정)
  "더(the) 잔잔". 물결이 잔잔하다는 뜻. 투약 앱임이 이름에 드러나지 않아 잠금화면에 떠도 명상·일기 앱처럼 보인다. 스토어 영문명 `Janjan`, 도메인 후보 `thejanjan.app`. 상표(KIPRIS 09·42·44류)는 로고 결합상표로 출원 예정. 검토 후 뺀 이름: 약속 / 필로그 / 도즈.

- **2026-08-17 · 플랫폼은 iOS + watchOS 전용** (확정)
  안드로이드 계획 없음. iOS 17+ / watchOS 10+. 1차 시장 한국, 한·영 2개 언어.

- **2026-08-17 · Capacitor(웹) 대신 SwiftUI 네이티브** (확정)
  이전 앱(러비티) 교훈. 워치 앱·알림 액션·컴플리케이션은 네이티브가 아니면 사실상 불가. 코드량은 늘지만 심사 예외 케이스가 줄어든다.

- **2026-08-17 · 로그인 없음 · 서버 없음 · 광고 없음** (확정)
  SwiftData + CloudKit **private** DB만 사용. 개발자가 데이터를 볼 수 없는 구조 → Privacy Label "데이터를 수집하지 않음", 건강정보 광고 금지(5.1.3) 회피, Sign in with Apple·계정 삭제·client secret 갱신 이슈 원천 제거. 분석·크래시 서드파티 SDK도 v1엔 없음.

- **2026-08-17 · 수익화는 Pro 구독** (확정)
  구독 그룹 1개 · 상품 2개(`pro_monthly`, `pro_yearly`), entitlement 이름은 `pro` 하나. **월 ₩2,900 / 연 ₩19,900**, 7일 무료 체험은 **연간에만**. 연간이 기본 선택("월 ₩1,658 꼴" 표기). 가격은 출시 3개월 지표로 재조정.

- **2026-08-17 · 무료 / Pro 경계** (확정)
  무료 = 약 등록·복약 알림·복용/건너뜀/30분 뒤·잔여 개수·수동 보충·약 용도 한 줄 메모·기분 7단계 하루 1회·증상 빠른 기록·최근 2주 캘린더·앱 잠금·데이터 삭제·로컬 백업 내보내기. 이것만으로도 앱이 완결적으로 쓸모 있어야 한다(심사·별점).
  Pro = Apple Watch 앱 전체 · 약봉투 스캔/지난 처방 복사/일괄 등록 · 소진 예측과 진료일 기준 부족 알림 · 감정 단어·수면·꿈·활동 태그·증상 상세 · 기분일기 2층 · 약 알아보기/증상으로 약 찾기/약 모양으로 찾기 · 전체 기간 캘린더·검색·리포트·PDF·CSV · iCloud 동기화·대체 아이콘·테마.

- **2026-08-17 · Pro 유도는 딱 세 곳** (확정)
  워치 앱 첫 실행 / 약 추가의 "스캔" / 리포트 탭·진료 D-1 알림. 홈 배너·팝업·카운트다운 없음.

- **2026-08-17 · 기분 척도는 7단계 + 감정 단어** (확정)
  −3 ~ +3 (매우 힘듦 · 힘듦 · 조금 힘듦 · 그저 그럼 · 조금 괜찮음 · 괜찮음 · 좋음). 점수는 "얼마나", 감정 단어(36개 + 직접 추가)는 "어떤". 감정 단어 칩은 좋은/나쁜을 색으로 편 가르지 않고 전부 같은 회색.

- **2026-08-17 · 기분일기는 2층 구조** (확정)
  1층 = 기분 원 하나(3초, 무료·워치), 저장 후 "한 줄 남길까요?"가 조용히 펼쳐짐. 2층 = 감정 단어·에너지/불안 5단계·수면과 꿈·활동 태그·질문 카드 1장·길이 제한 없는 긴 글·온디바이스 받아쓰기(Pro). 어느 층에서 멈춰도 완전한 기록이며 나중에 덧붙일 수 있다.

- **2026-08-17 · 질문 카드는 30개 중 하루 1장** (확정)
  넘기기 가능. 존댓말, 판단·평가 없음. → `data/question_cards.json`

- **2026-08-17 · 증상 카탈로그는 일상어로, 진단명 없음** (확정)
  3개 묶음(기분·불안 / 수면·에너지·인지 / 신체·부작용 의심). 공통 세기 0–10 + 항목별 보조 필드 1개(없음 / 시간 / 관련 약). 사용자 정의 항목도 동일하게 동작. → `data/symptom_catalog.json`

- **2026-08-17 · 약 DB는 식약처 공공데이터 번들** (확정)
  e약은요(효능효과·주의·이상반응 원문) + 낱알식별(모양·색·각인·저해상 이미지) + 의약품 허가정보. 공공누리 1유형, 앱 내 출처·기준일 표기. 정신건강 관련 성분 약 120종 × 상품명 약 600개를 오프라인 번들로. 약학정보원은 **앱 밖 외부 링크로만** 연결하고 내용을 복제하지 않는다.

- **2026-08-17 · 판단 기능은 넣지 않는다** (확정)
  용량 조절 권고·상호작용 판정·약 추천 없음. 원문 인용 + 출처 표기만. "증상으로 약 찾기"도 화면에 "검색 결과일 뿐 추천이 아님"을 명시. App Store 1.4.1 / 국내 의료기기 해당 여부 회피의 핵심.

- **2026-08-17 · 안전 카드** (확정)
  '자해·자살 생각'을 저장할 때, 또는 기분 '매우 힘듦(−3)'이 3일 연속일 때 표시. **109**(자살예방상담, 24시간) · **1577-0199**(정신건강위기상담) · 응급 112/119. 해외 로케일은 지역 번호. 닫기 가능하고 기록은 방해 없이 저장되며, 앱은 어떤 판단·진단·경고 문구도 붙이지 않는다.

- **2026-08-17 · 재고 = 사건의 합** (확정)
  잔여는 저장하지 않고 매번 다시 계산한다: **마지막 직접 정정 시점 이후 (보충 합 − 복용 합)**. 건너뜀·미기록은 차감하지 않음, 반쪽 복용은 0.25 단위 소수 허용. 예상 소진일 = 잔여 ÷ (하루 예정 개수 × 최근 4주 복약률). 부족 알림은 약별이 아니라 "다음 진료 전에 모자라는 약"으로 묶어 한 번. 이 계산은 순수 Swift 모듈로 분리해 단위 테스트 100%.

- **2026-08-17 · 비주얼 톤** (확정)
  연회색 바탕 + 알약처럼 둥근 흰 카드 + 얇고 큰 제목 + 파스텔 타일 + 화면당 검은 원 버튼 하나.
  Fog `#F2F2F0`(바탕) · Sage `#CBDAD5`(복용/완료) · Lavender `#DDD9F2`(감정/밤) · Butter `#F1EEA9`(아침/강조) · Peach `#F4E1D6`(건너뜀/주의) · Ink `#1C1C1B`(글자/검은 버튼).
  타이포는 **SUIT Light 300** 제목 + **Pretendard 400/500** 본문(둘 다 SIL OFL). 색만으로 상태를 말하지 않고 항상 글자·모양이 함께. 성별 코드·캐릭터·이모지 없음. → `design/tokens.json`

- **2026-08-17 · 말투 규칙** (확정)
  존댓말, 이모지 없음, 한 문장에 한 정보. "복약을 놓쳤습니다!" → "아침 약이 아직 남아 있어요". streak·연속기록 압박 없음. 건너뜀도 정상적인 선택으로 기록.

- **2026-08-17 · 배포는 GitHub Actions(macOS runner) → TestFlight** (반영)
  Archive → Export → 업로드까지 자동화. 인증서는 App Store Connect API 키로 자동 서명, 맥에서는 첫 인증서 등록만. 워크플로 골격은 `.github/workflows/ios-testflight.yml`에 있으나 프로젝트 골격 생성 전까지 비활성(`workflow_dispatch`).
