# 번들 데이터

앱에 **읽기 전용으로 번들**되는 JSON 카탈로그입니다. 네트워크 요청 없이 오프라인에서 동작하며, 갱신은 앱 업데이트로만 이뤄집니다(분기 1회 목표).

| 파일 | 내용 | 상태 |
| --- | --- | --- |
| `drug_catalog.json` | 약 정보 카탈로그 | 미생성 (스키마만 있음) |
| `symptom_catalog.json` | 증상 카탈로그 기본 목록 | 초안 |
| `emotion_words.json` | 감정 단어 36개 | 초안 |
| `question_cards.json` | 기분일기 질문 카드 30장 | 초안 |
| `schema/drug_catalog.schema.json` | `drug_catalog.json` 의 JSON Schema (draft-07) | 초안 |

---

## `drug_catalog.json`

국내 정신건강 관련 성분 약 120종 × 상품명 약 600개. 항목당 필드:

- **성분명 / 상품명[] / 제약사** — 상품명은 동일 성분의 여러 제품
- **계열** — SSRI, SNRI, 비정형 항정신병약, 벤조디아제핀 등
- **규격[] / 제형** — mg 단위 목록, 정제·캡슐·서방정 등
- **효능효과 원문 / 이상반응 원문 / 주의사항 원문** — 식약처 문구를 **손대지 않고 그대로** 싣는다
- **낱알 식별** — 모양·색(앞/뒤)·각인(앞/뒤)·분할선·크기, 저해상 이미지 파일명
- **출처 / 기준일** — 화면에 항상 함께 노출

### 출처와 라이선스

- 식약처 **공공데이터포털** 오픈 API — `e약은요`(의약품개요정보), `의약품 낱알식별 정보`, `의약품 허가정보`
- **공공누리 제1유형** (출처 표시 조건부 자유 이용). 앱 내 약 정보 카드 하단에 출처와 기준일을 반드시 표기.
- **약학정보원**은 데이터를 복제하지 않고 "더 자세히 보기" **외부 링크로만** 연결한다.

### 넣지 않는 것

용량 조절 권고, 상호작용 판정, 약 추천, 증상 개선 문구. 원문 인용 + 출처 표기까지만 — App Store 1.4.1 및 국내 의료기기 해당 여부를 피하는 선입니다. 저해상 낱알 이미지(약 4MB)는 번들해 오프라인 검색이 밖으로 나가지 않게 합니다.

## `symptom_catalog.json`

3개 묶음(`mood_anxiety` / `sleep_energy_cognition` / `body_side_effects`). 항목마다 공통 세기 0–10 위에 보조 필드 1개만 붙습니다.

- `aux_field: "none"` — 보조 입력 없음 (촉발 상황 태그는 공통 입력으로 별도 제공)
- `aux_field: "time"` — 수면 항목의 시간 입력
- `aux_field: "medication"` — 관련 약 + 복용 후 경과 시간(자동 계산). 꿈 항목은 "새 약 시작 후 며칠째"를 자동 표시
- `safety: true` — 저장 시 안전 카드를 띄우는 항목

사용자 정의 항목도 이름 + 보조 필드 유형만 정하면 동일하게 동작합니다.

## `emotion_words.json`

3묶음(`hard` / `neutral` / `good`) 36개. UI에서는 **전부 같은 회색 칩**으로 보여 좋은/나쁜 감정을 시각적으로 편 가르지 않습니다. 직접 추가 가능하며, 자주 쓰는 8개가 먼저 노출되고 리포트에는 주별 상위 3개로 요약합니다.

## `question_cards.json`

기분일기 2층에 하루 1장 노출, 넘기기 가능. 존댓말이며 판단·평가·조언을 담지 않습니다.
